# VeinMinerRevived
A Minecraft Forge mod made to give ease to mining clumps of ores, logs and more! All with the power of crouching!
(still needs work)

Visit Modrinth or Curseforge for .jar downloads.  
https://modrinth.com/mod/vein-miner-revived/  
https://legacy.curseforge.com/minecraft/mc-mods/vein-miner-revived

Using forge-1.18.2-40.3.11-mdk.zip.
skipped using IntelliJ, in trade for VSCode. (be sure to run ./gradlew genVSCodeRuns)

1) Build your gradle
2) Insert /src/ and relevant files
3) Edit gradle.properties 'org.gradle.java.home=' to your correct JDK
